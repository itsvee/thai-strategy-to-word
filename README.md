# Thai Strategy to Word

Skill สำหรับถามตอบเกี่ยวกับบริษัท ค้นหาปัญหา ทดสอบโจทย์ วิเคราะห์กลยุทธ์ และเขียนรายงานภาษาไทยก่อนส่งออก Word ใช้งานกับบริษัทอื่นได้โดยไม่ต้องมีรายงานเดิม

## ติดตั้ง

แตก ZIP แล้วนำทั้งโฟลเดอร์ `thai-strategy-to-word` ไปไว้ในไดเรกทอรี Skill ของเครื่องมือที่ใช้ เช่น `~/.agents/skills/` สำหรับสภาพแวดล้อมที่รองรับ shared skills หรือ `~/.codex/skills/` สำหรับ Codex ตรวจเอกสารของโฮสต์เรื่องตำแหน่งที่รองรับ หากมีชื่อเดิมอยู่ให้สำรองก่อน ห้ามรวมทับโดยไม่ตรวจรุ่น เปิด session ใหม่เมื่อโฮสต์โหลดรายการ Skill ตอนเริ่ม session

ต้องติดตั้ง `thai-docx` แยกเพื่อสร้าง Word: https://github.com/sayam/thai-docx-skill อ่านวิธีติดตั้งและคำสั่งของ dependency จากแหล่งนั้น ชุดนี้ไม่รวมตัวสร้าง DOCX ไม่ดาวน์โหลดโปรแกรมเอง และไม่อ้างว่าติดตั้ง dependency แล้ว สามารถเริ่มสัมภาษณ์และวิเคราะห์ได้ก่อน แต่ถ้าไม่มี dependency จะยังส่งออก Word ไม่สำเร็จ

ตัวตรวจความพร้อมใช้ Python 3.11 ขึ้นไปและ standard library เท่านั้น ไม่เรียกเครือข่าย ไม่มี API key ที่บังคับ การค้นข้อมูลสาธารณะและอ่านไฟล์ใช้ความสามารถของโฮสต์

## Prompt เริ่มต้น

### ยังไม่รู้ว่าต้องแก้อะไร

> ใช้ Skill thai-strategy-to-word ช่วยถามเกี่ยวกับบริษัทของฉันก่อน ตอนนี้ยังไม่รู้ว่าปัญหาสำคัญคืออะไร ให้ถามจากเหตุการณ์จริง ไล่หาสาเหตุและข้อจำกัดจนสรุปโจทย์ที่วิเคราะห์ได้ อย่าเพิ่งเขียนรายงานหรือสร้าง Word จนกว่าฉันจะยืนยันโจทย์

### มีปัญหาที่อยากแก้

> ใช้ thai-strategy-to-word บริษัทของฉันทำธุรกิจ [อธิบายธุรกิจ] และต้องการแก้ [อาการหรือปัญหา] ช่วย grill ทีละประเด็นจนมีข้อมูลพอวิเคราะห์ Framework แล้วเขียนข้อเสนอภาษาไทยสำหรับ [ผู้รับรายงาน] พร้อม Word โดยไม่แต่งตัวเลขที่ยังไม่มี

### มีรายงานและ feedback

> ใช้ thai-strategy-to-word ปรับรายงานที่แนบตาม feedback นี้ อ่านต้นฉบับก่อน ถามเฉพาะสิ่งที่ยังขาดหรือขัดกัน ยืนยันโจทย์และ trade-off กับฉันก่อนวิเคราะห์ต่อ จากนั้นเขียนรายงานไทยและสร้าง Word ฉบับใหม่ พร้อมสรุปว่าแก้ feedback แต่ละข้อที่ใด

## ผู้ใช้จะพบขั้นตอนอะไร

เริ่มจากบริษัทและบทบาท → เหตุการณ์/ปัญหา → ผลที่ต้องการและข้อจำกัด → หลักฐานและช่องว่าง → สรุปให้ยืนยัน → วิเคราะห์ Framework → เขียนไทย → ตรวจ → Word

จำนวนคำถามขึ้นกับสิ่งที่ยังไม่รู้ ไม่บังคับจำนวนรอบ หากไม่ทราบต้นทุนหรือค่าฐาน ผู้ช่วยจะถามเจ้าของข้อมูล วิธี และเวลาที่จะเก็บ และให้ยอมรับแผนก่อน ไม่สร้าง ROI หรือผลลดสิ่งแวดล้อมแทนข้อมูลที่ขาด ถ้าไม่มีปัญหาที่ชัดแม้สำรวจแล้ว ให้ส่งแผนเก็บข้อมูลและ checkpoint แทนรายงานที่แสร้งวิเคราะห์เสร็จ

## ไฟล์ในชุด

- `SKILL.md`: กระบวนการหลักและ Gate
- `references/interview.md`: ลำดับถามตอบและทางแยก Discovery/Revision
- `references/readiness.md`: ความพร้อมและสัญญาข้อมูล
- `references/frameworks.md`: หลักใช้ Framework และข้อควรระวัง
- `references/evidence.md`: สถานะหลักฐาน ความลับ และข้อมูลขัดกัน
- `references/thai-writing.md`: น้ำเสียงและโครงภาษาไทยแบบรายงานผู้บริหาร
- `references/verification.md`: ตรวจเนื้อหาและไฟล์ก่อนส่ง
- `templates/state.example.json`: โครงเก็บสถานะที่ยังไม่พร้อม ต้องคัดลอกไป workspace ของกรณี
- `templates/report-outline.md`: โครงรายงานหกหมวดที่ปรับตามธุรกิจ
- `scripts/readiness_gate.py`: ตัวตรวจความครบของสถานะ
- `tests/test_readiness_gate.py`: ทดสอบพฤติกรรมตัวตรวจ
- `tests/scenarios.md`: กรณีประเมินบทสนทนา

## คำสั่ง

แทน `<skill>` ด้วยโฟลเดอร์ที่ติดตั้ง และ `<workspace>` ด้วยพื้นที่เก็บกรณีของผู้ใช้:

```text
python <skill>/scripts/readiness_gate.py <workspace>/interview-state.json
python <skill>/tests/test_readiness_gate.py
```

ตัวตรวจคืน `needs_interview`, `ready_for_confirmation` หรือ `ready_for_analysis` โดย exit 0 เฉพาะพร้อมวิเคราะห์ exit 2 เมื่อยังไม่พร้อม และ exit 1 เมื่อไฟล์หรือข้อมูลผิดรูปแบบ ผู้ช่วยยังต้องตรวจคุณภาพคำตอบและความถูกต้องของหลักฐานเอง ตัวตรวจไม่ได้เข้าใจเนื้อหาธุรกิจแทนคน

## สิ่งที่ส่งมอบจากการใช้ Skill

สถานะสัมภาษณ์และสรุปโจทย์ยืนยัน ทะเบียนหลักฐานกับข้อจำกัด การวิเคราะห์ที่เชื่อมการตัดสินใจ รายงาน Markdown และ Word ฉบับใหม่พร้อมผลตรวจจริง เก็บไฟล์ทั้งหมดในพื้นที่ของผู้ใช้ ไม่ใส่ข้อมูลบริษัทในโฟลเดอร์ Skill หรือแพ็กที่แชร์ต่อ

## รูปแบบรายงาน

เขียนภาษาไทยทางการที่อ่านต่อเนื่อง หัวข้อเป็นข้อความเชิงบริหาร มีข้อค้นพบ เหตุผล และผลต่อการตัดสินใจ ไม่ตอบคำถามชั้นเรียนเป็นข้อ ๆ ใช้ตารางเฉพาะข้อมูลที่ควรเปรียบเทียบ คงศัพท์มาตรฐานและแยกข้อเท็จจริง สมมติฐาน กับข้อเสนอ รายงานเน้นให้ผู้อ่านตัดสินใจต่อได้ ไม่ถือว่าผู้ช่วยอนุมัติหรือรับรองผลแทนบริษัท
