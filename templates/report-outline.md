# โครงรายงานหลังผ่าน Gate

ไฟล์นี้เป็นโครงสำหรับผู้ช่วย ไม่ใช่ข้อความให้คัดลงรายงานทั้งดุ้น ปรับชื่อหมวดให้ตรงธุรกิจ ไม่ส่งช่องว่างหรือข้อความกำกับการเขียนเป็นรายงานสำเร็จ

## ส่วนต้น

ชื่อบันทึกข้อเสนอ ชื่อบริษัท ช่วงแผน ผู้รับรายงาน ผู้จัดทำเมื่อทราบ และสถานะข้อเสนอ ห้ามใส่ชื่อผู้อนุมัติหรือมติที่ยังไม่มีจริง

บทสรุปผู้บริหาร: ปัญหาและผลต่อธุรกิจ หลักฐานสำคัญ ทางเลือกที่เสนอ สิ่งที่ยอมแลก ผลที่ต้องการ ทรัพยากร และข้อเสนอเพื่อพิจารณา ระบุชัดว่าเป็นการอนุมัติทิศทาง การทดลอง หรือวงเงิน หากวงเงินยังไม่ทราบให้แสดงแผนประมาณการและอำนาจอนุมัติก่อนใช้เงินจริง

## หกหมวดหลัก

1. บริบทเชิงกลยุทธ์และจุดยืนการแข่งขันของบริษัท: องค์กร ลูกค้า แบบจำลองธุรกิจ ผู้มีส่วนได้เสีย ทรัพยากร Empathy Map, VPC และการเปลี่ยน BMC
2. กรอบการคุ้มครองมูลค่าและสร้างการเติบโต: เหตุผลเลือกกลยุทธ์ ความเชื่อมโยง Value Protection/Creation สิ่งที่ทำ ไม่ทำ และยอมแลก เป้าหมายที่เสนอ
3. การประเมินสภาพแวดล้อมและออกแบบความยั่งยืน: Materiality, PESTEL, Five Forces, SWOT/TOWS และการคัดทางเลือก SVAT, TBL และ LCA Screening เมื่อเกี่ยวข้อง พร้อมข้อจำกัด
4. แผนปฏิบัติการและความพร้อมองค์กร: โครงการ Roadmap, Gate, McKinsey 7S, RACI, Skill Matrix, 3C แผนทรัพยากรและงานช่วงแรก
5. ระบบติดตาม ประเมินผล และกำกับดูแล: Backward Logic Model, KPI dictionary, แหล่งข้อมูล รอบรายงาน PDCA การประเมินความคุ้มค่าและผลกระทบ และแนวทางเปิดเผยข้อมูลที่เกี่ยวข้อง
6. กรณีธุรกิจ ความเสี่ยง และเงื่อนไขความสำเร็จ: วิธีคำนวณประโยชน์และต้นทุน ฉากทัศน์ ACAT Risk Register ข้อตกลงพันธมิตร SDG targets ที่เกี่ยวข้อง และการตัดสินใจที่ขอ

## ส่วนท้าย

เอกสารอ้างอิงที่ใช้จริง ขอบเขตข้อมูลภายใน สมมติฐานและแผนเก็บข้อมูล ตารางวิเคราะห์รายละเอียด และ feedback coverage สำหรับงานปรับปรุง แยกเนื้อหาวิชาการ/แหล่งแนวคิดจากการระบุว่าผู้อ่านเป็นผู้บริหาร ไม่จำเป็นต้องลบอ้างอิงการเรียนเพื่อเปลี่ยนกลุ่มผู้อ่าน

## รูปแบบ Word

ค่าจัดรูปแบบตามผู้ใช้และ thai-docx หากไม่ได้ขอให้ใช้ค่าปริยายของ dependency ไม่เพิ่มสารบัญ เลขหน้า หรือฟอนต์เองเพียงเพราะเป็นรายงาน เก็บ Markdown เป็นฉบับแก้ไขต่อและใช้ชื่อ DOCX ใหม่ เลขหัวข้อที่พิมพ์เป็นข้อความไม่เปลี่ยนอัตโนมัติเมื่อแก้ใน Word ให้บอกเมื่อเกี่ยวข้อง
