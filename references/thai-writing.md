# ภาษาไทยสำหรับข้อเสนอผู้บริหาร

เป้าหมายคือภาษาไทยทางการที่อ่านต่อเนื่อง เข้าใจข้อเสนอและเหตุผลได้โดยไม่ต้องแปลโครงสร้างอังกฤษกลับในใจ น้ำเสียงตรง สุภาพ ไม่โฆษณา ไม่ใช่คำตอบข้อสอบ และไม่ทำให้ความแน่นอนสูงกว่าหลักฐาน

## โครงย่อหน้า

หนึ่งย่อหน้าพัฒนาหนึ่งประเด็น เริ่มด้วยข้อค้นพบหรือข้อเสนอ ตามด้วยหลักฐานหรือเหตุผล แล้วบอกผลต่อการตัดสินใจ สลับความยาวประโยคตามเนื้อหา ใช้ประธานชัดเมื่อเปลี่ยนผู้รับผิดชอบ ลดนามธรรมซ้อน เช่น “การดำเนินการในการพัฒนา” เป็น “พัฒนา”

ใช้หัวข้อข้อความเชิงบริหาร เช่น “ความถูกต้องของบริการเป็นเงื่อนไขก่อนขยายการเติบโต” ไม่ใช้ “จะทำอย่างไรให้โต?” หัวข้อห้ามคัดคำถามโจทย์มาวางไว้ คำถามใช้ในบทสัมภาษณ์เท่านั้น

เชื่อมบทตามเหตุผล: บริบททำให้เห็นปัญหา ปัญหาทำให้ต้องเลือก ทางเลือกทำให้ต้องจัดทรัพยากร และทรัพยากรต้องมีหลักฐานวัดผล ไม่เติม “นอกจากนี้” หรือ “อย่างไรก็ตาม” ทุกย่อหน้า หลีกเลี่ยงประโยคเดียวที่ต่อรายการด้วยอัฒภาคหลายช่วง

## คำและน้ำหนักหลักฐาน

- ใช้ “ข้อมูลภายในระบุว่า…” เมื่อยังเป็นคำบอกเล่า ไม่เปลี่ยนเป็น “บริษัทมี…” โดยไม่มีหลักฐานเพิ่ม
- ใช้ “เสนอให้…” สำหรับการตัดสินใจใหม่ และ “คาดว่า…ซึ่งต้องทดสอบ…” สำหรับผลที่ยังไม่เกิด
- “พบข้อร้องเรียนในชุดข้อมูล…” ไม่เท่ากับ “ลูกค้าทั้งหมดพบปัญหา…”
- “ผ่านการอบรม” ไม่เท่ากับ “ทำงานได้ตามระดับทักษะ”
- “จัดทำระบบแล้ว” เป็น Output ต้องพิสูจน์ Outcome แยก
- ไม่ใช้ “พิสูจน์ว่า”, “รับประกัน”, “ยั่งยืนแน่นอน” หรือ “พร้อมอนุมัติงบ” ถ้าหลักฐานยังไม่ถึง

ศัพท์มาตรฐานใช้ English ได้ โดยอธิบายไทยเมื่อใช้ครั้งแรกและใช้คำเดิมสม่ำเสมอ เช่น ข้อตกลงระดับบริการ (SLA) ไม่แปลชื่อ API ชื่อบริษัท หรือชื่อมาตรฐานจนเสียความหมาย ไม่บังคับให้ผู้ใช้พูดศัพท์เหล่านี้ในบทสัมภาษณ์

## ตาราง

ใช้ตารางเมื่อมีตัวเลือก ตัวเลข สูตร owner ความรับผิดชอบ หรือ mapping จริง โดยทั่วไปไม่เกินห้าคอลัมน์ ถ้ากว้างให้แยกนิยามกับการกำกับเป็นคนละตาราง แต่ต้องใช้รหัสเชื่อมเดียวกัน เขียนย่อหน้าก่อนหรือหลังเพื่อบอกว่าตารางทำให้เลือกอะไร ไม่แทนเหตุผลทั้งบทด้วยตาราง

## ตัวอย่างการเรียบเรียงต้นฉบับสมมติ

เดิม: บริษัทควรยกระดับการบูรณาการประสิทธิภาพเชิงกลยุทธ์อย่างยั่งยืนด้วยเทคโนโลยีที่ทันสมัย

ปรับ: เสนอให้ตรวจความถูกต้องของรายการก่อนเพิ่มช่องทางขาย เพราะงานแก้รายการซ้ำใช้เวลาทีมที่ต้องส่งมอบบริการเดิม การขยายงานจึงควรรอให้ผ่านเกณฑ์คุณภาพที่ผู้บริหารเห็นชอบ

เดิม: การอบรมทำให้ทีมมีความพร้อมและรายได้เพิ่มขึ้น

ปรับ: การอบรมเป็นผลส่งมอบระยะแรก หัวหน้าทีมต้องตรวจชิ้นงานและการปฏิบัติจริงก่อนมอบหมายงานสำคัญ ส่วนผลต่อรายได้ยังต้องประเมินร่วมกับต้นทุนและข้อมูลลูกค้า

เดิม: ลดน้ำหนักวัสดุแล้วจึงลดคาร์บอนได้ทันที

ปรับ: การทดลองจะวัดวัสดุที่ใช้ร่วมกับความเสียหายและการส่งทดแทน ข้อมูลน้ำหนักเพียงอย่างเดียวยังไม่เพียงพอให้สรุปผลลดคาร์บอน

## ตรวจภาษาและรูปแบบก่อนส่ง

อ่านเนื้อหาแบบผู้อ่านผู้บริหารหนึ่งรอบ ตรวจว่าทุกย่อหน้ามีข้อเสนอ ข้อเท็จจริง เหตุผล หรือข้อจำกัดที่จำเป็น ตัดประโยคชมแผนและสรุปซ้ำ ใช้เลข ปี พ.ศ./ค.ศ. หน่วย และชื่อเฉพาะตรงกัน ไม่เติมช่องว่างระหว่างคำไทยเพื่อบังคับตัดบรรทัด ห้าม zero-width characters ใช้ย่อหน้าและการเว้นวรรคตามธรรมชาติ

หากมี Skill kien-thai ให้ใช้ช่วยตรวจ แต่คู่มือนี้ใช้ได้เองโดยไม่ต้องพึ่งโมเดลไทยเฉพาะ ห้ามอ้างว่าได้รับการตรวจโดยเจ้าของภาษาถ้ายังไม่ได้ทำจริง
