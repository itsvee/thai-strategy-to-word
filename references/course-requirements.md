# ข้อกำหนดรายงานสำหรับทุกอุตสาหกรรม

ที่มา: คำถามแปดข้อจากบันทึกงาน และ feedback อาจารย์ที่ผู้ใช้ให้ในบทสนทนา ไม่ใช่เฉลยหรือ rubric คะแนนที่ได้รับการรับรอง ไม่เก็บชื่อบริษัท ตำแหน่ง ตัวเลข หรือปัญหาเฉพาะบุคคลไว้เป็นค่าเริ่มต้น

## คำถามต้องตอบ

- Q1 จะสร้างธุรกิจที่ยั่งยืนได้อย่างไร
- Q2 อธิบายองค์กรของคุณ
- Q3 อธิบายกลยุทธ์ทางธุรกิจ
- Q4 วางแผนกลยุทธ์นั้นมาอย่างไร
- Q5 ออกแบบกลยุทธ์อย่างไร
- Q6 นำไปปฏิบัติอย่างไร
- Q7 ติดตามและประเมินผลอย่างไร
- Q8 กลยุทธ์ช่วยให้ธุรกิจยั่งยืนขึ้นได้อย่างไร

ผู้ช่วยต้องสร้าง coverage ครบ Q1–Q8 และทุกข้อจาก feedback ก่อนส่งออก ต้องเทียบรายการกับเอกสารนี้ ไม่ถือว่า JSON ผ่านเท่ากับเนื้อหาครบ

## รูปแบบตาม feedback

ผู้อ่านคือผู้มีอำนาจตัดสินใจในองค์กรที่ผู้ใช้เลือก เอกสารเป็นบันทึกเสนอแผนกลยุทธ์และทรัพยากร ไม่เปิดเรื่องด้วยวัตถุประสงค์ส่งรายวิชา มีบทสรุปผู้บริหารและเอกสารอ้างอิง หัวข้อหลักและย่อยเป็นข้อความเชิงบริหารทั้งหมด ไม่ใช้คำถาม

เดินเรื่องผ่าน Value Protection และ Value Creation โดยหาหลักฐานขององค์กรนั้น ไม่สมมติว่าต้องแก้ระบบแต้ม แอป การซื้อซ้ำ หรือบรรจุภัณฑ์ เป้าหมายคือให้ผู้บริหารเข้าใจทางเลือก ทรัพยากร เจ้าของงาน เงื่อนไขผ่าน/หยุด และข้อจำกัด ถ้างบไม่ทราบให้เสนออนุมัติทิศทาง/การประเมิน ห้ามแต่งวงเงินหรืออ้างพร้อมอนุมัติงบ

## หกหมวดและข้อเสนอแนะที่ต้องตอบ

1. บริบทองค์กรและจุดยืนการแข่งขัน: Empathy Map และ VPC เปรียบเทียบผู้รับคุณค่ากับทีมส่งมอบ เชื่อมสิ่งที่ต้องปรับใน BMC เก้าช่อง แยกคำสัมภาษณ์จริงจากข้อสันนิษฐาน
2. กรอบคุ้มครองมูลค่าและสร้างมูลค่าใหม่: กลยุทธ์ เหตุผลเลือก สิ่งที่ไม่ทำ สิ่งที่ยอมแลก ผลต่อองค์กรและผู้มีส่วนได้เสีย
3. สภาพแวดล้อมและการออกแบบความยั่งยืน: PESTEL, Five Forces, SWOT/TOWS, Impact–Difficulty, Materiality และ Double Materiality อธิบายเกณฑ์/น้ำหนัก/ผู้ประเมินในเนื้อหาหลัก ไม่ตั้ง 50/50 เอง Stakeholder Importance ไม่ใช่ Impact Materiality โดยอัตโนมัติ เพิ่ม SVAT ครอบคลุม Captured, Missed, Destroyed, Surplus, Absence และ Opportunities พร้อม TBL และ LCA Screening ของวงจรผลิตภัณฑ์หรือบริการที่เกี่ยวข้อง
4. แผนปฏิบัติการและความพร้อม: ระยะเตรียมพร้อม ทดลอง และขยาย ปรับเวลาตามหลักฐาน ไม่คัดลอกปีตัวอย่าง มี Gate, RACI, 3C และ McKinsey 7S ครบเจ็ดองค์ประกอบ เพิ่ม Skill Matrix ตามบทบาทจริง SLO/DPIA ใช้เมื่อเกี่ยวข้อง ไม่สมมติทุกธุรกิจมีทีมวิศวกรรม ประเมินทักษะไม่ได้ให้ระบุยังไม่ประเมินพร้อมวิธีเก็บข้อมูล
5. การวัดผลและเปิดเผยข้อมูล: Backward Logic Model, SMART KPIs, baseline หรือแผนเก็บ, owner, รอบรายงาน, PDCA และวงประชุมทบทวน เชื่อม SET Corporate Sustainability Guide เป็นแนวทาง ไม่ถือว่าบริษัทจดทะเบียน เลือก GRI ตามผลกระทบจริง เช่น 306 สำหรับขยะและ 418 สำหรับความเป็นส่วนตัว ตรวจมาตรฐานต้นทางก่อนอ้าง compliance
6. กรณีธุรกิจและเงื่อนไขสำเร็จ: ประโยชน์ ต้นทุน สมมติฐาน ไม่คิดประโยชน์ซ้ำ เชื่อม SDG targets ที่พิสูจน์ผลได้ ข้อตกลงพันธมิตรเมื่อเกี่ยวข้อง มี Risk Register พร้อม owner, trigger, ACAT และความเสี่ยงคงเหลือ ไม่สมมติว่ามีสัญญาพันธมิตรแต้ม

ทุกข้อของ feedback ต้องมีผลตอบ: วิเคราะห์ด้วยหลักฐาน / ข้อเสนอพร้อมวิธีพิสูจน์ / ข้อจำกัดพร้อมแผนเก็บข้อมูล / เหตุผลไม่เกี่ยวข้องที่ตรวจได้ ห้ามใช้ not_applicable ลบคำถาม Q1–Q8 หรือเครื่องมือบังคับโดยพลการ

## ข้อกำหนดที่ห้ามแต่งเพิ่ม

ไม่มีจำนวนหน้าบังคับจากข้อมูลที่ได้รับ เป้า 25–30 หน้าเดิมเป็นแผนเขียน ไม่ใช่คำสั่งอาจารย์ ภาษาอังกฤษในบทสรุปต้องยึดคำสั่งเฉพาะงาน ไม่อ้างว่าอาจารย์บังคับสองภาษาโดยไม่มีหลักฐาน วันส่งและรายชื่อผู้บริหารต้องมาจากผู้ใช้ปัจจุบัน ไม่คัดลอกจากงานอื่น
