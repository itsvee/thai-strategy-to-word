# Framework ที่เชื่อมกับการตัดสินใจ

## เลือกเครื่องมือตามงาน

เริ่มจากโจทย์ที่ยืนยันแล้ว ไม่บังคับจำนวนกลยุทธ์ ระยะ หรือ KPI แบบกรณีใดกรณีหนึ่ง งานกลยุทธ์ความยั่งยืนเต็มรูปแบบควรครอบคลุมรายการด้านล่าง งานขอบเขตเล็กให้ระบุเหตุผลที่เว้นเครื่องมือที่ไม่เกี่ยวข้อง หากมี rubric หรือ feedback ให้ทำ coverage เพิ่มตามเอกสารจริง ไม่อ้างว่าทุกองค์กรต้องใช้ทุกเครื่องมือ

| ขั้น | เครื่องมือและข้อมูลนำเข้า | ผลที่ต้องใช้ตัดสินใจ |
|---|---|---|
| บริบทธุรกิจ | ขอบเขตองค์กร รายได้ ลูกค้า ทรัพยากร ห่วงโซ่คุณค่า และผู้มีส่วนได้เสีย | ระบุจุดที่มีอำนาจควบคุม จุดที่มีอิทธิพล และข้อจำกัดจริง |
| ลูกค้าและทีม | Empathy Map, VPC, Customer Journey จากเหตุการณ์/หลักฐาน | แยกความต้องการผู้ใช้กับภาระทีม แล้วกำหนดคุณค่าที่ส่งมอบได้ |
| แบบจำลองธุรกิจ | BMC ทั้งเก้าช่อง | ชี้ช่องที่ต้องเปลี่ยนและผลต่อรายได้ ต้นทุน คน หรือพันธมิตร |
| ประเด็นสำคัญ | Materiality และ Double Materiality ตามความเหมาะสม | กำหนดเกณฑ์และลำดับลงทุนที่ตรวจเหตุผลได้ |
| สภาพแวดล้อม | PESTEL, Five Forces, Benchmark, ฉากทัศน์ | แยกแรงกดดันจริงจากสมมติฐานและกำหนดเงื่อนไขทบทวน |
| ทางเลือก | SWOT → TOWS → Impact–Difficulty | เปรียบเทียบทางเลือก เหตุผลเลือก สิ่งที่ไม่ทำ และสิ่งที่ยอมแลก |
| คุณค่าความยั่งยืน | SVAT, TBL, การคิดเชิงระบบและ LCA Screening เมื่อเกี่ยวข้อง | เปิดคุณค่าที่ตกหล่นและป้องกันย้ายผลกระทบไปผู้อื่น |
| ปฏิบัติการ | 7S, Skill Matrix, 3C, Roadmap, RACI และประมาณการทรัพยากร | กำหนด owner ผลส่งมอบ เวลา ทรัพยากร และ Gate |
| กำกับผล | Backward Logic Model, KPI, PDCA และ ACAT | ระบุหลักฐานที่พิสูจน์ผลและเงื่อนไขหยุด/ปรับ/ขยาย |
| กรณีธุรกิจ | CBA ฉากทัศน์ และความไวของสมมติฐาน | แยก Value Protection กับ Value Creation และประโยชน์ที่นับซ้ำ |

## ลูกค้า ทีม และ BMC

Empathy Map ต้องมีสิ่งที่เห็น ได้ยิน พูด/ทำ คิด/รู้สึก Pain และ Gain ถ้าความรู้สึกอนุมานให้ติดป้ายสมมติฐาน ห้ามแต่งคำสัมภาษณ์ เปรียบเทียบผู้ใช้กับทีมที่ต้องส่งมอบ แล้วใช้ VPC จับ Customer Jobs/Pains/Gains กับ Products and Services/Pain Relievers/Gain Creators

BMC ครบ Customer Segments, Value Propositions, Channels, Customer Relationships, Revenue Streams, Key Resources, Key Activities, Key Partnerships และ Cost Structure ให้แสดงสภาพที่ทราบ การปรับที่เสนอ และผลต่อการตัดสินใจ ห้ามใส่อัตราค่าธรรมเนียมหรือสัดส่วนรายได้จากบริษัทตัวอย่าง

## Materiality และ Double Materiality

นิยามแกน ช่วงคะแนน ผู้ให้คะแนน หลักฐาน และเหตุผลน้ำหนัก หากใช้ Business Impact กับ Stakeholder Importance จัดลำดับ ต้องระบุว่าความสำคัญต่อผู้เกี่ยวข้องไม่ใช่ผลกระทบต่อคนและสิ่งแวดล้อมโดยอัตโนมัติ Double Materiality ประเมินผลกระทบที่องค์กรก่อ/มีส่วนร่วม/เชื่อมโยงแยกจากความเสี่ยงและโอกาสทางการเงิน

ไม่บังคับน้ำหนัก 50/50 คะแนนที่ผู้ช่วยเสนอเป็นเพียงการประเมินเสนอ ไม่ใช่ผลรับฟังที่เกิดแล้ว แสดงคะแนนแยกแกนและไม่ให้ค่าเฉลี่ยกลบผลกระทบสิทธิ ความปลอดภัย หรือข้อกฎหมายที่ต้องจัดการ หากยังไม่มีข้อมูลเพียงพอให้ใช้ลำดับเบื้องต้นเชิงคุณภาพและแผนยืนยัน แทนตัวเลขแม่นยำเทียม

## SWOT, TOWS และทางเลือก

S/W เป็นภายใน O/T เป็นภายนอก ต้องมีข้อมูลเปรียบเทียบก่อนอ้างความเหนือกว่า จับคู่ SO/ST/WO/WT เท่าที่มีเหตุผล ไม่สร้างทุกคู่เพื่อให้เต็มตาราง Impact–Difficulty ใช้ระดับที่นิยามและระบุว่าเป็นดุลยพินิจหรือผลประชุมจริง คัดทางเลือกจากผลต่อปัญหา ความพร้อม และสิ่งที่ยอมแลก ไม่ให้คะแนนแทนการตัดสินใจทั้งหมด

## SVAT และวงจรชีวิต

กำหนดหน่วยวิเคราะห์และผู้มีส่วนได้เสีย รวมสังคมกับสิ่งแวดล้อม แยก Value Captured จาก Value Uncaptured สี่แบบ: Value Missed, Value Destroyed, Value Surplus และ Value Absence แล้วแสดง Value Opportunities ที่ทำได้ ไม่อ้างว่าได้รับการรับรองจาก Cambridge

LCA Screening ใช้เมื่อมีผลกระทบผลิตภัณฑ์หรือบริการที่เกี่ยวข้อง ต้องมีเป้าหมาย หน่วยหน้าที่ ขอบเขตระบบ แหล่งข้อมูล คุณภาพข้อมูล ทางเลือกที่เทียบเคียง และผลที่ยังสรุปไม่ได้ รวมคืนสินค้า ส่งทดแทน และผลข้ามขั้นตอนเมื่อเกี่ยวข้อง ไม่เรียก screening ว่าผ่าน LCA ตาม ISO เต็มรูปแบบ ไม่ถือมวลลดเท่ากับคาร์บอนลด หรือวัสดุรีไซเคิลได้เท่ากับถูกรีไซเคิลจริง ธุรกิจบริการใช้วงจรบริการที่ตรงบริบท ไม่เพิ่มบรรจุภัณฑ์ที่ธุรกิจไม่มี

TBL ต้องแสดงความตึงเครียด Economy–Society, Society–Environment, Environment–Economy พร้อมมาตรการและข้อจำกัด ใช้ Nested Model เพื่อไม่ให้กำไรชดเชยการละเมิดสิทธิหรือข้อจำกัดสิ่งแวดล้อมโดยไม่มีเกณฑ์

## ปฏิบัติการและทักษะ

7S ครบ Strategy, Structure, Systems, Shared Values, Style, Staff, Skills แต่ละข้อชี้ช่องว่างและการเปลี่ยนงาน Skill Matrix เลือกทักษะตามปัญหา เช่น SLO/DPIA ใช้เฉพาะบริบทที่ต้องใช้ ไม่บังคับกับทุกบริษัท ระบุ current=ยังไม่ประเมินได้ ไม่แต่งคะแนน เป้าหมายเป็นข้อเสนอและต้องมีหลักฐานทำงาน ไม่ใช้การอบรมแทนสมรรถนะ

RACI มี A หนึ่งบทบาทต่อ initiative ไม่เท่ากับอำนาจอนุมัติวงเงินทุกระดับ Roadmap ต้องไม่เปิดระยะถัดไปก่อน Gate พร้อมแม้วันคาบเกี่ยว งบรวมต้องบวกได้และแยกเงินสดเพิ่ม เวลาทีม และต้นทุนโอกาส หากไม่ทราบวงเงินให้ขออนุมัติทิศทางแบบมีเงื่อนไขพร้อมแผนประมาณการ ไม่เรียกว่าอนุมัติงบพร้อมใช้

## การวัดผล ความเสี่ยง และรายงาน

Backward Logic Model ออกแบบ Impact → Outcome → Output → Activity/Input พร้อมสมมติฐานและวิธีพิสูจน์ KPI มีสูตร ตัวหาร หน่วย ค่าฐาน ขอบเขต เป้า กำหนด owner ความถี่ และแหล่งข้อมูล ค่าไม่ทราบไม่ใช่ศูนย์ เป้าใหม่ต้องระบุว่าเสนอและใครอนุมัติ เปรียบเทียบช่วงเวลาเดียวกัน และใช้กลุ่มเปรียบเทียบเมื่ออ้างผลเชิงเหตุ

ACAT: Avoid ไม่ทำกิจกรรมเสี่ยงเกินเกณฑ์; Control ลดโอกาส/ผลกระทบ; Accept ยอมรับคงเหลือโดยผู้มีอำนาจ; Transfer แบ่งภาระที่โอนได้แต่ไม่ลบความรับผิดทางกฎหมาย Risk Register ต้องมีเหตุ ผลกระทบ owner trigger มาตรการ และวิธีประเมินความเสี่ยงคงเหลือ ไม่ลดระดับเพียงเพราะเขียนมาตรการไว้

SET Guide เป็นแนวทางได้โดยไม่สมมติว่าบริษัทจดทะเบียน เลือก GRI ตามประเด็นจริง ไม่ยัด GRI 306/418 ทุกธุรกิจ ถ้าใช้ 306 ให้แยกวัสดุที่ใช้ ขยะที่เกิด การเบี่ยงเบน และปลายทางกำจัด ถ้าใช้ 418 ให้แยกข้อร้องเรียนที่ยืนยันและเหตุข้อมูลที่ตรวจพบ การ mapping ไม่ใช่การรายงานสอดคล้องครบถ้วน ตรวจมาตรฐานฉบับทางการก่อนใช้รายละเอียด

SDGs เลือกเฉพาะ target ที่องค์กรมีผลหรืออิทธิพลและมีวิธีพิสูจน์ ไม่ใช้ตรา SDG เป็นหลักฐานความสำเร็จ Business Case ไม่ใช้ GMV แทนรายได้ ไม่แปลงเวลาประหยัดเป็นเงินสดอัตโนมัติ ไม่รวมผลรักษาฐานกับซื้อซ้ำทับกัน และไม่คำนวณ ROI จากตัวเลขที่สร้างขึ้น
